# System Design Interview Preparation

A comprehensive learning resource for software engineers with 2 years of experience preparing for system design interviews.

## Contents

- [System Design Learning Plan](SYSTEM_DESIGN_LEARNING_PLAN.md) - Complete 7-day roadmap with concepts, practice problems, and interview strategies
- [System Design Notes](SYSTEM_DESIGN_NOTES.md) - Concise study notes for quick revision and memorization

## Overview

This repository contains a structured learning plan specifically designed for Associate/Junior SDE candidates (2 YOE) who are preparing for system design interviews during their job search.

### What's Included

- **7-Day Learning Roadmap** - Day-by-day plan covering all essential topics
- **Core Concepts** - APIs, Databases, Caching, Load Balancing, Message Queues
- **Interview Framework** - The RADIO method for structured answers
- **Practice Problems** - URL Shortener, Rate Limiter, Notification System, Chat App
- **Common Mistakes** - What to avoid during interviews
- **Quick Reference** - Cheat sheets for database selection, scaling, and estimations

### Target Audience

- Software engineers with 1-3 years of experience
- Candidates preparing for Associate/Junior level positions
- Anyone who needs to learn system design from fundamentals

### How to Use

1. Follow the 7-day roadmap sequentially
2. Practice each concept with the provided exercises
3. Work through the practice problems with solutions
4. Use the interview framework during mock interviews
5. Review the cheat sheet before actual interviews

## Quick Start

Start with [Day 1: Fundamentals & APIs](SYSTEM_DESIGN_LEARNING_PLAN.md#day-1-fundamentals--apis) and progress through the roadmap.
